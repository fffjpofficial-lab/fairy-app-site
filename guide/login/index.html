はじめての利用・ログイン

ログインには、店舗が発行するログインID と、ご自分で設定するパスワードを使います。最初のパスワードの設定とパスワードの再設定は、店舗が案内するWebページで行います。

STEP 0

用意するもの

ログインID
店舗が発行する半角数字8桁の番号です。メールアドレスではありません。
設定コード
最初のパスワードを設定するためのコードです。店舗のスタッフから対面で受け取ります。一度だけ使え、有効期限は発行から72時間です。

ログインID はご自分で決めるものではありません

ログインID は店舗が発行します。アプリでは変更できません。ログインした後は、マイページでいつでも確認できます。

STEP 1

最初のパスワードを設定する

最初のパスワードは、アプリではなく、店舗が案内するWebページ（「アカウント設定」のページ）で設定します。ページのアドレスと設定コードは、店舗のスタッフが案内します。パスワードを設定してから、アプリにログインします。

  1. 店舗から案内されたページを開きます。「アカウント設定」と表示されるページです。
  2. セットアップコード に、店舗から受け取った設定コードを入力します。
  3. パスワード と パスワード確認 に、同じパスワードを入力します。10〜16文字の半角英数字で、大文字・小文字・数字をそれぞれ1文字以上含めてください。
  4. アカウントを有効化 を押します。「アカウント設定が完了しました」と表示されたら完了です。Webページでログインする必要はありません。
  5. アプリを開き、ログインID と設定したパスワードでログインします。次の ログインする をご覧ください。

アプリのログイン画面の 初めて利用する方 を押すと、店舗から受け取ったコードで最初のパスワードを設定する、という簡単な案内が表示されます。

設定コードの有効期限が切れたときは

コードは発行から72時間で使えなくなります。使えないときは、店舗に新しいコードの発行を依頼してください。

STEP 2

ログインする

  1. アプリを開きます。「ログインIDとパスワードを入力してください」と表示されます。
  2. ログインID に、半角数字8桁を入力します。数字のキーボードが開きます。
  3. パスワード に、設定したパスワードを入力します。右端の目のアイコンで、入力した文字を表示・非表示にできます。
  4. ログイン を押します。「確認しています…」「読み込み中…」の後、ホーム画面が開きます。

ログインできないとき

ログイン画面に表示されるメッセージと、確認することです。

  • ログインIDは半角数字8桁です8桁の半角数字を入力してください。全角の数字やメールアドレスは使えません。
  • ログインIDまたはパスワードを確認してください。ログインID かパスワードが違います。どちらが違うかは表示されません。入力し直しても分からないときは、パスワードの再設定を店舗に依頼してください。
  • 通信できませんでした。時間をおいてもう一度お試しください。通信の状態を確認し、少し時間をおいてからもう一度お試しください。
  • ログインIDを入力してくださいパスワードを入力してください入力欄が空のままです。ログインID とパスワードの両方を入力してください。

ログインに失敗すると、パスワードの入力欄は空になります。ログインID は残ります。

「このアカウントでは出演者アプリを利用できません。」と表示されたとき

このアカウントは出演者アプリで利用できない状態です。店舗の担当者へお問い合わせください。ログアウト を押すと、ログイン画面に戻ります。

「情報を取得できませんでした。」と表示されたときは、通信の状態を確認して 再試行 を押してください。

パスワードを忘れたとき

パスワードを忘れた場合は、所属店舗のスタッフにお問い合わせください。メールなどで自分だけで再設定する方法はありません。アプリの パスワードを忘れた方 を押すと、店舗のスタッフに問い合わせるよう案内が表示されます。

  1. 店舗に連絡し、パスワードの再設定を依頼します。スタッフが本人であることを確認し、再設定コードを対面で渡します。再設定コードの有効期限は60分です。
  2. 店舗から案内されたページを開きます。「パスワード再設定」と表示されるページです。
  3. 再設定コード、新しいパスワード、新しいパスワード（確認） を入力し、パスワードを再設定 を押します。「パスワードを再設定しました」と表示されたら完了です。
  4. アプリで、ログインID と新しいパスワードでログインします。

再設定すると、ログインし直しになります

パスワードを再設定すると、ほかの端末を含め、ログインしていた状態がすべて終わります。アプリはログイン画面に戻ります。すぐに戻らないときは、アプリを開き直してください。

ログインの状態

  • 一度ログインすると、ログアウトするまで、次からはログインID とパスワードを入力せずに使えます。
  • ログインの状態はその端末の中にだけ保存されます。機種を変えたときや、アプリを入れ直したときは、もう一度ログインしてください。
  • ほかの人の端末でログインしないでください。使い終わったら ログアウト できます。

パスワードは本人だけが入力してください

ログインID・パスワード・設定コードを、ほかの人に教えないでください。店舗やこのサイトがパスワードを尋ねることはありません。

  • 初めてで、パスワードがありません
