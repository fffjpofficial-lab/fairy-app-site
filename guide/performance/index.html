実績の確認

今月の実績と目標、期間とサイトを選んだポイントの集計を確認できます。実績は店舗が日ごとに確定した後に反映されます。

実績の画面の開き方

ホームの 今月のポイント のカードをタップすると、「実績」の画面が開きます。実績は画面の下のメニューにはありません。

実績の画面には「今月の実績」と「ポイント集計」の2つがあります。左上の戻るボタンでホームに戻ります。

画面を下に引っ張ると、最新の内容を読み込みます。

今月の実績

ポイント
今月獲得したポイントと、「YYYY/MM/DD 更新」（その日までの実績が反映されている）
目標
今月の目標、「あと ○○ pt」、達成率。達成すると「目標達成」
現在の時間単価
1時間あたりのポイント。算出できないときは「算出できません」と表示されます。
残り必要pt/h
目標の達成に、残りの配信予定時間で1時間あたり必要なポイントと、残り配信予定時間

表示できない理由があるときは、数字の代わりに理由が表示されます（例:「目標達成済みです」「残りの配信予定時間がないため算出できません」「休止のため対象外です」「まだ反映されていません」）。

  • 今月の目標は設定されていません目標は店舗が設定します。
  • 今月は休止のため、目標は対象外です休止の月の表示です。

目標ペース（目標との差）は、ホームの「今月のポイント」に表示されます。

ポイント集計

期間とサイトを選んで、ポイントの合計と内訳を確認できます。画面を開くと、前日から今日まで・全サイトで1回集計されます。

まだ反映されていない日は 0 pt と表示されます

ポイント集計では、店舗の確定がまだの日のポイントは 0 pt と表示されます。今日の分はまだ反映されていないため、最初の「前日から今日まで」の集計は 0 pt になることがよくあります。集計の結果の「YYYY/MM/DD 更新」の日付より後の日は、まだ反映されていません。日付が表示されていないときは、選んだ期間の実績がまだ反映されていないか、確認できない状態です。

  1. 開始日 と 終了日 を、年・月・日から選びます。
  2. サイト で、全サイト か、確認したいサイトを選びます。
  3. 集計 を押します。選んだ期間とサイト、ポイントの合計、ポイント内訳が表示されます。反映済みの日があるときは「YYYY/MM/DD 更新」も表示されます。

集計の結果とポイント内訳

  • 「ポイント内訳」: パーティ・のぞき・2ショット・双方向・秘密メッセージ・メール・チップ・その他 の8項目のポイントと割合が、色分けの棒と一覧で表示されます。
  • 内訳がない項目は「—」と表示されます。内訳の一部を表示できないときは「※一部のポイント内訳は表示されていません」と表示されます。

選べる期間

長さ
最大31日（開始日と終了日を含む）。月をまたいでも指定できます。
選べる日
今日まで（未来の日は選べません）。今年と過去2年
  • 開始日は終了日以前の日付にしてください開始日を、終了日と同じ日かそれより前にしてください。
  • 期間は31日以内で指定してください期間を31日以内にしてください。
  • 未来の日付は指定できません今日までの日を選んでください。

実績の反映のタイミング

実績は、店舗が日ごとに確定した後に反映されます

今日の分は、今日のうちには表示されません。「YYYY/MM/DD 更新」の日付で、どの日までの実績かを確認してください。

  • 実績はまだ更新されていません店舗の実績がまだ反映されていない状態です。0 pt という意味ではありません。
  • 今月の実績はまだ反映されていません今月分の実績がまだ確定していない状態です。0 pt という意味ではありません。
  • この期間の実績は確認できませんどの日までの実績が反映されているかを確認できない状態です。0 pt という意味ではありません。

表示に疑問があるときは店舗にご相談ください。
