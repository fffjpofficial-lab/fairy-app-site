通知・お知らせ

ルームや補填の通知と、店舗からのお知らせは、ホーム右上のベルで確認できます。スマートフォンに届く Push 通知と、その設定もここで説明します。

ベルの通知の一覧

  1. ホームの右上のベルを押します。まだ見ていない通知があると、ベルに件数が付きます（100件以上は「99+」）。
  2. 「通知」の画面が開きます。新しい通知から順に並びます。各行には通知の種類と日時（「2026-11-19 00:42」など）が表示されます。まだ開いていない通知は、ピンクの背景と右端の点で表示されます。
  3. 通知を押すと、その内容の画面が開きます。通知の種類ごとの移動先は、下の 通知の種類 をご覧ください。

画面を下に引っ張ると、最新の通知を読み込みます。左上の ‹ でホームに戻ります。

チャットはベルに入りません

店舗からのチャットの新着は、画面の下の チャット のボタンの件数で確認します（チャット）。

通知の種類

本日のルームが決まりました
出勤する日に、その日の Room が決まったことのお知らせです。押すとホームが開き、Room を確認できます。
補填日の提出が必要です
補填日の登録が必要な欠勤があることのお知らせです。押すと欠勤・補填の画面が開きます（欠勤・補填）。
新しいお知らせがあります
店舗から新しいお知らせが届いたことのお知らせです。押すとそのお知らせの詳細が開きます（お知らせ）。

ルームの通知が届くとき

  • 出勤する日の 0:00 の時点で Room が割り当てられていれば、その日のうちに通知されます。
  • 0:00 の時点で Room が決まっていないときは、その日に Room が割り当てられたときに通知されます。
  • 通知は1つの出勤予定につき1回です。その後に Room が変わったり、割り当てが解除されたりしても、もう一度は通知されません。最新の Room は、ホームやカレンダーで確認してください。
  • 在宅の出勤には Room がないため、通知はありません。

補填日の提出の通知が届くとき

  • 補填が必要な欠勤1件につき、1回だけ通知されます。
  • 補填日を登録した後に、もう一度通知されることはありません。登録の状況は欠勤・補填の画面で確認できます。
  • 通知はありませんまだ通知が届いていない状態です。
  • 通知を読み込めませんでした。通信状況を確認して、もう一度お試しください。通信の状態を確認して、もう一度読み込む を押してください。
  • この通知はもう表示できません。内容が取り消された・期間が過ぎたなどの理由で、開けない通知です。

ベルの通知は、作られてから3か月を過ぎると一覧に表示されなくなります。

お知らせ

店舗からのお知らせは、ベルの画面から開きます。ホームにはお知らせの入口はありません。

  1. ベルの「通知」の画面で、いちばん上の お知らせの一覧 を押します。
  2. 「お知らせ」の一覧が開きます。新しいものから順に、タイトルと日時が並びます。まだ読んでいないお知らせは、ピンクの背景と右端の点で表示されます。
  3. お知らせを押すと、詳細が開きます。タイトル・日時・本文・画像が表示されます。公開の後に店舗が内容を直したお知らせには「編集済み」と表示されます。画像を押すと大きく表示され、閉じる で戻ります。

「新しいお知らせがあります」の通知を押したときは、そのお知らせの詳細が直接開きます。

お知らせは、公開から3か月を過ぎると表示されなくなります。

  • お知らせはありませんまだお知らせが届いていない状態です。
  • このお知らせは表示できません。取り下げられた・期間が過ぎたなどの理由で、開けないお知らせです。

Push 通知

アプリを閉じているときも、スマートフォンの通知（Push 通知）でお知らせします。

はじめて使うとき

  1. ログインした後に、端末から「"Fairy" は通知を送信します。よろしいですか？」のような確認が表示されます。表示の文言は、端末と OS のバージョンによって異なります。
  2. 許可 を押すと、Push 通知を受け取れるようになります。許可しなくてもアプリは使えます。後から許可するときは 通知設定 をご覧ください。

届く Push 通知

チャット
「新着メッセージがあります」。押すとチャットが開きます。
お知らせ
「新しいお知らせがあります」。押すとそのお知らせが開きます。
ルーム
「本日のルームが決まりました」。押すとホームが開きます。
補填
「補填日の提出が必要です」。押すと欠勤・補填の画面が開きます。

Push 通知には内容は表示されません

Push 通知には、メッセージの本文・画像・店舗名などは表示されません。内容はアプリを開いて確認してください。開いたときにログインの状態を確かめてから、最新の内容を表示します。

  • アプリを開いて使っている間は、Push 通知は表示されません。ベルの件数・チャットの件数で確認できます。
  • ログアウトすると、その端末には Push 通知が届かなくなります。

通知設定

  1. マイページの「アカウント設定」で、通知設定 を押します。
  2. いちばん上に端末の通知の状態、その下に種類ごとの「Push通知」のスイッチが表示されます。
端末の通知: オン
この端末で Push 通知を受け取れます。
端末の通知: オフ
端末の設定で通知が許可されていないため、Push 通知は届きません。端末の設定を開く から許可してください。
端末の通知: 未設定
まだ通知を許可していません。通知を許可する を押すと、端末の確認が表示されます。
端末の通知: 利用できません
この端末では Push 通知を受け取れません。ベルの一覧では確認できます。

種類ごとの Push 通知

「Push通知」の欄の チャット・お知らせ・ルーム・補填 のスイッチで、種類ごとに Push 通知を受け取るかを選べます。スイッチを切り替えると、すぐに保存されます。

  • オフにした種類は、Push 通知だけが届かなくなります。ルーム・補填・お知らせは、オフにしてもベルの一覧には表示されます。
  • チャットの新着は、オフにしてもチャットのボタンの件数で確認できます。
  • 「お知らせ」の設定を保存できませんでした。元の設定に戻しました。通信の状態を確認して、もう一度切り替えてください（「」の中は切り替えた種類）。
  • 通知設定を読み込めませんでした。通信状況を確認して、もう一度お試しください。もう一度読み込む を押してください。

端末の通知の許可

Push 通知を受け取るには、端末の設定で Fairy の通知を許可しておく必要があります。

iPhone
「設定」>「通知」>「Fairy」で「通知を許可」をオンにします。
Android
「設定」>「アプリ」>「Fairy」>「通知」で通知をオンにします。Android では、チャット・お知らせ・ルーム・補填の種類ごとに、端末の側でも通知のオン・オフを選べます。

画面の名前や場所は、端末のメーカーや OS のバージョンによって異なります。アプリの 通知設定 の 端末の設定を開く からも開けます。

Push 通知が届かないとき

  1. アプリの通知設定で「端末の通知: オン」になっているか確かめます。
  2. 届かない種類のスイッチが、オンになっているか確かめます。
  3. 端末の「おやすみモード」「集中モード」や省電力の設定を確かめます。
  4. ログインしているか確かめます。ログアウトしている間は、Push 通知は届きません。

Push 通知が届かなくても、ベルの一覧とチャットの件数では確認できます。
